# RB Portfolio (Rooholah)

پرتفلیوی دوزبانه (فارسی/انگلیسی) با انیمیشن ورودی ذره‌ای. بدون npm، بدون فریم‌ورک، بدون build.
حجم کل حدود ۹۰ کیلوبایت و کد (JS+HTML) حدود ۱۱ کیلوبایت gzip.

## اجرا
فایل‌ها ES module هستن، پس با دابل‌کلیک روی index.html (file://) کار نمی‌کنن. یکی از این‌ها:

1. VS Code: افزونه‌ی Live Server → راست‌کلیک روی `index.html` → Open with Live Server
2. ترمینال داخل پوشه: `python -m http.server 5500` و بعد باز کردن `http://localhost:5500`
3. یا: `npx serve .`

## ویرایش
- همه‌ی متن‌ها و لینک‌ها: `js/content.js`
  - `LINKS`: ایمیل، اینستاگرام (`YOUR_PAGE`)، تلگرام (`YOUR_ID`)، گیت‌هاب (`YOUR_USERNAME`) رو عوض کن. آیتمی که نمی‌خوای رو از آرایه‌ی `['email','instagram','telegram','github']` توی `js/main.js` حذف کن.
  - رزومه: فایل PDF رو با اسم `assets/resume.pdf` بذار.
- عکس پرتره‌ی ذره‌ای: `assets/avatar.webp` (PNG شفاف، کوچیک). هر عکس شفاف دیگه‌ای هم جواب می‌ده.
- رنگ‌ها: متغیرهای بالای CSS توی `index.html` (`--gold` و ...).
- مدت انیمیشن و تعداد ذره: `T_END` توی `js/intro.js` و عدد ۹۰۰۰ / ۴۲۰۰ توی `js/main.js`.

## نکته‌ها
- دکمه‌ی Skip هست؛ بعد از یک‌بار دیدن، توی همون نشست انیمیشن رد می‌شه؛ با `prefers-reduced-motion` هم رد می‌شه.
- برای دیدن یه لحظه‌ی مشخص از انیمیشن: `index.html?t=3.2`
- فونت Kalameh از fontiran.com است و برای استفاده روی وب‌سایت لایسنس می‌خواد؛ مطمئن شو لایسنس داری.

## افکت‌های جدید (اسکرول، متن ذره‌ای، آهن‌ربا)
- `js/textfx.js`: همه‌ی منطق متن‌ها.
  - **هاور روی تیترها**: تیترهای بزرگ (PORTFOLIO، Intro، Projects، Skills، Contact) با رد شدن موس مثل رنگ کنار می‌رن و آروم برمی‌گردن. تیتر جدید: `tx.add(element)` توی `js/main.js`.
  - **اسکرول Intro ← Projects**: سکشن Intro پین می‌شه؛ متن به ذره، ذره‌ها به یک کره‌ی نورانی، کره روی `ROUTE` حرکت می‌کنه و به Projects تبدیل می‌شه. مسیر: آرایه‌ی `ROUTE` (نسبت به صفحه، چپ‌به‌راست؛ توی RTL خودکار آینه می‌شه). زمان‌بندی: `PH`. طول اسکرول: `280vh` توی `.scene` در `index.html`.
- `js/particles.js`: آهن‌ربای آواتار. `RING_R` (شعاع) و `RING_W` (ضخامت) حلقه‌ی دور موس. فقط روی دستگاه‌های دارای موس فعاله.
- با `prefers-reduced-motion` همه‌ی این افکت‌ها خاموشه و صفحه ساده نمایش داده می‌شه.
